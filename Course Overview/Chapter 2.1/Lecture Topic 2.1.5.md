CC configuration, Characteristics of CC configuration:

The configuration in which the collector is common between emitter and base is known as CC configuration. In CC configuration, the input circuit is connected between emitter and base and the output is taken from the collector and emitter. The collector is common to both the input and output circuit and hence the name common collector connection or common collector configuration.

Fig.1 Common Collector Configuration

## Input Characteristic Curve

The input characteristic of the common collector configuration is drawn between collector base voltage VCE and base current IB at constant emitter current voltage VCE. The value of the output voltage VCE changes with respect to the input voltage VBC and IB With the help of these values, input characteristic curve is drawn. Fig.2 Input curve of common collector configuration

## Output Characteristic Curve

The output characteristic of the common emitter circuit is drawn between the emitter-collector voltage VEC and output current IE at constant input current IB. If the input current IB is zero, then the collector current also becomes zero, and no current flows through the transistor.
